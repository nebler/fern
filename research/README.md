# Research

Files in this directory are dated evidence, independent audits, prompts, and
decision memos. They preserve what was known and argued at the recorded time;
they are not implementation or roadmap contracts and may intentionally disagree.

Use the following authority order:

1. Code and tests for implemented behavior.
2. [`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) and
   [`docs/TASK_MODEL.md`](../docs/TASK_MODEL.md) for maintained technical
   contracts.
3. [`docs/REMOTE_PRODUCT.md`](../docs/REMOTE_PRODUCT.md) for accepted product
   direction.
4. [`docs/ROADMAP.md`](../docs/ROADMAP.md) and
   [`todo/opencode-background-mode.md`](../todo/opencode-background-mode.md) for
   current sequencing and acceptance gates.

The three 2026-08-30 remote-agent wedge reports are retained as independent
inputs. Their shared conclusion is a bounded OpenCode Background Mode
falsification experiment, not authorization for a generic remote-agent platform
or a Kubernetes migration.
