# Go skills

These 20 `go-*` skills are copied unchanged from [cxuu/golang-skills](https://github.com/cxuu/golang-skills) at commit `91f0c2eef559` (Apache-2.0, see `LICENSE-golang-skills`). They are built from the Google Go Style Guide, Effective Go, the Uber Go Style Guide and Go Code Review Comments.

Agents load them on demand. [AGENTS.md](../../AGENTS.md) is the rulebook: where a skill and AGENTS.md disagree, AGENTS.md wins.

To update: copy the `skills/` folder from a newer commit, read the diff, and change the commit above.
