# Historical Product Research

The `r1.md` through `r7.md` files are point-in-time research from
their recorded dates. They are retained as evidence and may contain stale
implementation findings or rejected alternatives.

`code-review-p0-p1.md` is likewise a point-in-time review; resolved findings
remain in the file as history.

Files under [`research/`](../research/) are also dated evidence rather than
current contracts; see [`research/README.md`](../research/README.md).

Do not use these audits as the current product or architecture contract:

- [`docs/REMOTE_PRODUCT.md`](../docs/REMOTE_PRODUCT.md) is authoritative for
  product direction.
- [`docs/ROADMAP.md`](../docs/ROADMAP.md) is authoritative for ordered future
  work and acceptance criteria.
- [`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) and the code are
  authoritative for implemented behavior.
- [`docs/FIELD_DEMO.md`](../docs/FIELD_DEMO.md) is authoritative for the phone
  demo claim and procedure.
