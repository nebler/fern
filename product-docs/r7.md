## 1. Verdict up front

The ladder's *shopping list* survives. Its *model*, its *ordering*, and three of its effort
estimates do not.

1. **The model changes.** "Evidence × legibility" omits the term that dominates outcomes:
   **distribution**, plus a relevance gate and a sign. Sharper version:

   `Value = Channel(P_seen, referral-weighted) × Gate(role-relevant) × max(0,
   Verifiable-in-a-90s-review + Discussable) − Disqualifiers`

   Consequence: a perfect repo no reviewer opens is worth zero; a referral bypasses the
   artifact entirely; and the artifact's real job at Grab is **not** to be scored — it is to
   (a) differentiate you at recruiter triage, (b) survive a hiring-manager deep-dive
   conversation, (c) pre-answer system-design questions. Evidence below.
2. **The ordering inverts in the middle.** The original ladder puts the terminal-success
   observer *before* the gateway because the demo "dies at running/input_required." Wrong for
   this purpose: **user-authorized sealing already ships** (`seal-preview`/`seal` API routes;
   code review P0/P1), so the demo arc completes manually today. Better: demo the manual seal
   and *explain why automatic success-proof is hard* (cite anomalyco/opencode #38458) — that is
   a stronger interview answer than a feature. Gateway moves ahead of the observer.
3. **Effort corrections:** gateway-MVP-with-metering in 3 weekends is fantasy — **4–5
   weekends** for the credible version (the SSE/metering subtleties are exactly the part worth
   doing and exactly what costs time). Freezer pause is 1 weekend of code, not 2. Observer is
   ~2. Legibility rung is 1–2 (README rewrites always overrun).
4. **Two missing rungs, both cheaper than anything on the ladder:** **referral outreach**
   (the channel term — NodeFlair's 290-interview compilation ranks referrals first among ways
   to get interviewed; a 2021 first-hand account went referral→OA in 24h) and **interview-prep
   integration** (the loop is DSA + system design + 4H culture; your system-design prep should
   literally rehearse rate-limiter/API-gateway designs using fern vocabulary).
5. **Apply earlier than the ladder implies.** Official timeline ≈1 month application→outcome
   [OFFICIAL]; the HM round where your project gets discussed sits weeks after submission; and
   the req can close without notice (a Singapore merchant-AI req already did). Apply when the
   legibility rung + freezer numbers land (~weekend 3), build the gateway during the loop.

Net: same destination, reordered sequence, corrected budgets, two new rungs, and a much
smaller belief in what the repo itself does inside the loop.

## 3. How portfolios are actually evaluated (and what it implies)

Evidence base: interviewing.io × Learning Collider 2024 experiment (76 recruiters, ~2,200
evaluations: median screen **31 seconds**, accuracy vs actual outcomes 55%, inter-rater spread
41pp; >45s of attention improves accuracy) [survey/experiment]; Ladders eye-tracking (7s
resume triage) [vendor-run study]; CMU CSCW 2013 (employers form impressions from activity
traces and ownership, not close code reading) [academic]; convergent HM self-reports: profile →
pinned repos → **README first** → commits/tests only if hooked; cloning/running is rare; repos
frequently become **interview walkthrough material** ("I've used code from the candidate's
profile and had them walk me through it") [multiple independent anecdotes]. README research:
guideline-aligned sections correlate with popularity [academic, stars-not-hiring]; the
differentiating section is **Why/purpose — present in only ~25% of READMEs** [Prana et al.].
Simon Willison (HM): detailed description + screenshots "almost no-one does… massively
increases impact" [FIRST-HAND]. Merged-PR weight: Linux Foundation Jobs Report — 44% of HMs
name OSS contribution the most important technical qualification [survey, OSS-centric bias];
OpenCraft's handbook makes ≥1 merged non-trivial third-party PR a **hard pre-selection filter**
[OFFICIAL-for-them]; typo/drive-by PRs discounted everywhere. Video demos: **no measurement
exists**; consensus is GIF-at-top beats linked video at screening; broken links disqualify.
Distribution reality: an HN front-page day ≈ 3.5–4k visitors; Basecamp's 25 front-page posts →
105k visitors → 97 signups — reach ≠ pipeline; hiring value comes from a handful of relevant
readers plus direct channels.

**The sharp implications for you:**

1. **Legibility has a ceiling.** Past "understandable in 90 seconds," extra polish buys little
   because raters are noisy. The scarce output isn't "impressed" — it's **"advanced +
   discussable."** Optimize the repo to generate three great war stories, not admiration.
2. **Channel dominates.** A referral converts better than any artifact improvement. This is a
   LinkedIn-evenings activity, not a build weekend.
3. **Relevance is a gate, not a factor.** The freezer benchmark is lovely and largely
   irrelevant to this loop; the Redis limiter is boring and dead-center. Gate first.
