# Task 01: Add Clean-Checkout CI

## Commit

```text
ci: verify Go checks and workspace image build
```

## Purpose

Make the repository's existing claims independently checkable before remote deployment.

## Dependencies

Start from task `00`. Independent of tasks `02` through `08`.

## Owned Files

Create only `.github/workflows/ci.yml`. Task `09` owns badges and README changes.

## Required Jobs

The Go job must run:

```bash
test -z "$(gofmt -l .)"
GOTOOLCHAIN=local go test ./...
GOTOOLCHAIN=local go test -race ./...
GOTOOLCHAIN=local go vet ./...
GOTOOLCHAIN=local go build ./cmd/fern
```

The separate image job must run:

```bash
docker build -t fern/opencode:ci images/opencode
```

## Constraints

- Use the Go version declared by `go.mod`.
- Pin actions according to the repository's chosen policy.
- Use normal Go module caching and least-privilege permissions.
- Do not add coverage SaaS, a broad OS matrix, release publication, or image publication.
- Do not require task `07` until its environment contract exists.

## Acceptance

- Pull requests and the default branch trigger CI.
- Formatting, tests, race tests, vet and build are visible.
- Docker image failure is separately attributable.
- One clean run passes after all Wave 1 commits merge.
